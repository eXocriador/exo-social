# packages/

Пакети робочої області, які **не знають про продукт**: фабрики з явним конфігом,
без `process.env` і без імен маршрутів. Застосунки в `apps/*` їх збирають.

Порожньо з народження — і тека все одно потрібна: Dockerfile (архетип F3 kit)
копіює `packages` у стадії збірки й залежностей, а `git archive` порожньої теки
не несе. Цей файл і тримає її в дереві.
